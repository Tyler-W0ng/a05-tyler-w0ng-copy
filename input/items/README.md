# The development set

Six targets, one JSON file each, in the input format of the handout (§1).
`../known.json` lists their known vulnerabilities, in the format the grader
uses to match findings (same file, and the same function or a line range
within 10 lines). One target has no known vulnerability: it is pinned at a
version where it has been fixed.

The evaluation set is hidden; its targets are similar in kind.
